# doc-investigation-query (deprecated)

`/sdd:doc-investigation-query` is a deprecated alias of [`/sdd:ask`](../ask/README.md) `type:investigation`.

`/sdd:ask` searches all four registries (investigations included), loads only the documents that
match the question within a budget, and grounds every answer in `raw/`. Add `type:investigation`
to restrict it to investigations.
