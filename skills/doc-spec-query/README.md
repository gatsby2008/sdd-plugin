# doc-spec-query (deprecated)

`/sdd:doc-spec-query` is a deprecated alias of [`/sdd:ask`](../ask/README.md) `type:spec`.

`/sdd:ask` searches all four registries (specs included), loads only the documents that
match the question within a budget, and grounds every answer in `raw/`. Add `type:spec`
to restrict it to specs.
