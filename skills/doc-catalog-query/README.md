# doc-catalog-query (deprecated)

`/sdd:doc-catalog-query` is a deprecated alias of [`/sdd:ask`](../ask/README.md) `type:catalog`.

`/sdd:ask` searches all four registries (service catalogs included), loads only the documents that
match the question within a budget, and grounds every answer in `raw/`. Add `type:catalog`
to restrict it to service catalogs.
